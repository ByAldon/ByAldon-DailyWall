# Repository package notes

This folder is meant to be pushed to:

https://github.com/ByAldon/ByAldon-DailyWall

## What is included

- Python source files
- assets/icon.png
- assets/icon.ico
- empty wallpaper folders with .gitkeep
- config.json
- README.md
- LICENSE
- requirements.txt
- installer script folder

## What is intentionally not included

- downloaded wallpapers
- assets/history.json
- build/
- dist/
- .exe build output
- Python cache files
- local virtual environments

## Recommended first push

```powershell
git status
git add .
git commit -m "Update ByAldon DailyWall to v0.6.1"
git push
```
